# صورت مسئله و محدودهٔ پروژهٔ صفر

## داستان محصول

مایلو یک ربات با توان پردازشی محدود است. او در نخستین قدم از `PROJECT_MILO`، کانال ارتباطی `MILO_COMM` را ایجاد می‌کند تا بتواند از طریق API با یک مدل زبانی صحبت کند. خروجی پروژه باید این ارتباط را ابتدا در ترمینال و سپس در یک رابط وب واقعی نشان دهد.

## مسئله‌ای که حل می‌کنیم

کاربر باید بتواند بدون کار با API یا JSON، یک پیام طبیعی بنویسد و پاسخ مدل را دریافت کند. برنامه همچنین باید زمینهٔ پیام‌های قبلی همان نشست را نگه دارد تا گفت‌وگو واقعاً ادامه‌پذیر باشد.

## خروجی‌های الزامی

### خروجی ۱: برنامهٔ کنسولی Python

- دریافت متن از ترمینال؛
- ارسال پیام و تاریخچهٔ گفتگو به مدل؛
- نمایش پاسخ؛
- ادامه تا زمانی که کاربر دستور خروج بدهد؛
- امکان پاک‌کردن تاریخچه در همان نشست؛
- مدیریت خطا بدون نمایش traceback غیرضروری به کاربر.

### خروجی ۲: رابط وب Next.js

- رابط چت راست‌به‌چپ و قابل‌استفاده؛
- نمایش مجزای پیام کاربر و دستیار؛
- Route Handler سمت سرور برای تماس با مدل؛
- نمایش وضعیت انتظار و خطا؛
- ادامهٔ مکالمه در همان صفحه؛
- امکان شروع گفت‌وگوی جدید.

## خارج از محدودهٔ MVP

- ثبت‌نام و ورود کاربر؛
- دیتابیس و همگام‌سازی بین دستگاه‌ها؛
- آپلود فایل، تصویر یا صدا؛
- RAG، Vector DB، Tool Calling و MCP؛
- Agent loop یا اجرای خودکار ابزارها؛
- پرداخت، پنل مدیریت و چندمستاجری؛
- استریم پاسخ؛ استریم یک قابلیت تکمیلی است، نه شرط تحویل MVP.

## کاربر هدف

ارزیاب بوت‌کمپ یا کاربری که می‌خواهد در چند ثانیه یک مکالمهٔ کوتاه با مایلو داشته باشد. کاربر نباید برای استفاده از محصول نیاز به دانستن نام endpoint یا ساختار SDK داشته باشد.

## جریان اصلی

1. کاربر برنامه را باز می‌کند.
2. پیام خود را وارد می‌کند.
3. برنامه ورودی را اعتبارسنجی می‌کند.
4. درخواست از محیط امن سرور/ترمینال به API ارسال می‌شود.
5. پاسخ به تاریخچه افزوده و نمایش داده می‌شود.
6. کاربر پیام بعدی را می‌فرستد یا مکالمه را پاک/تمام می‌کند.

## معیارهای پذیرش

### رفتار اصلی

- پیام خالی ارسال نمی‌شود.
- دست‌کم پنج رفت‌وبرگشت متوالی بدون از دست رفتن زمینه انجام می‌شود.
- پاسخ دستیار کنار پیام‌های قبلی باقی می‌ماند.
- شکست شبکه، کلید نامعتبر، مدل نامعتبر و محدودیت نرخ به پیام قابل‌فهم تبدیل می‌شوند.
- برنامه بعد از یک خطای قابل‌بازیابی از کار نمی‌افتد.

### امنیت

- فایل‌های `.env` در `.gitignore` قرار دارند.
- فقط `.env.example` بدون مقدار واقعی commit می‌شود.
- کلید API در log، response مرورگر، HTML یا bundle کلاینت دیده نمی‌شود.
- endpoint وب ورودی را از نظر نوع، طول و نقش پیام‌ها بررسی می‌کند.

### کیفیت

- راه‌اندازی هر برنامه از روی README خودش قابل‌انجام است.
- نام‌ها و ساختار کد برای یک پروژهٔ آموزشی ساده‌اند.
- منطق تماس با مدل از UI جداست و امکان تعویض provider را دارد.
- حداقل تست‌های بدون شبکه برای اعتبارسنجی و تبدیل خطا وجود دارد.
